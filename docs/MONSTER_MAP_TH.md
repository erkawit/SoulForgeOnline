# แผนที่จุดเกิดมอนสเตอร์ — 23 ตุลาคม 2026

เปิดเกม กด **J → THREE CITIES** เลือกเมืองหลัก พื้นที่ล่า หรือดันเจี้ยน แล้วเลือกหมายเลขบนแผนที่หรือรายการด้านล่างเพื่อดูชื่อมอนสเตอร์ เลเวล พิกัด ประเภท และเวลาเกิดใหม่ ปุ่มเดินทางจะเข้าสู่พื้นที่ที่เลือกโดยเริ่มที่ Sanctuary ไม่ใช่พิกัดมอนสเตอร์

## ข้อมูลอ้างอิง

ใช้ลักษณะเมืองจาก `THREE_CITIES_UPDATE_TH.md` และใช้การแบ่งอาณาเขต/เลเวลจาก `docs/EXPANSION_UPDATE_TH.md` ซึ่งใหม่กว่า `WORLD_1_100_TH.md` ใช้ชื่อมอนสเตอร์ที่ปรับแล้วตาม `docs/BESTIARY_BOSSES_TH.md`

| เมืองหลัก | ลักษณะเมือง | เลเวลพื้นที่รอบเมือง |
|---|---|---|
| Hollow Reach | ป้อมกอธิก โรงหลอม ประตูสุสาน | 1, 5, 10, 20, 25, 30, 35, 40 |
| Dawnveil | วิหารริมคลองและสะพาน | 45, 60, 75, 79, 82 |
| Thornwatch | เมืองชายป่าและหอเฝ้าระวัง | 85, 90 |

คงพื้นที่ล่า 10 แห่งและดันเจี้ยน 3 แห่งตาม Expansion เมืองหลักยังมีจุดฝึกรอบนอกเมืองละ 6 จุด เลเวล 1/5/10 ตามระบบเดิม แต่ Dawnveil ใช้มอนสเตอร์ริมคลอง และ Thornwatch ใช้มอนสเตอร์ป่าแทนการใช้ชนิดจาก Hollow Reach ทั้งหมด พื้นที่ล่า/ดันเจี้ยนมีพื้นที่ละ 10 จุด รวม 148 จุด

## การเชื่อมกับเกม

- `src/game/content.ts`: ตำแหน่ง `hunt` อาคาร คลอง เมืองแม่ และเลเวล
- `src/game/spawns.ts`: รวมตำแหน่งกับชนิด เลเวล Elite/Boss และเวลาเกิดใหม่ เป็นข้อมูลกลางของแผนที่และการสร้างมอนสเตอร์
- `src/components/HuntingMap.tsx`: เลือกอาณาเขต พื้นที่ และจุดเกิด รองรับรายการปุ่มสำหรับคีย์บอร์ด/จอสัมผัส
- แผนที่ย่อแสดงวงตำแหน่งเกิดคงที่ควบคู่กับจุดมอนสเตอร์ที่เคลื่อนที่จริง ฉาก 3D แสดงวงบนพื้นตำแหน่งเดียวกัน
- มอนสเตอร์ธรรมดาเกิดใหม่ 8 วินาที บอส 5 นาที จุดบอสเป็นจุดสุดท้ายของดันเจี้ยน
- ทิศเหนือคือ Z ติดลบ วงกลางรัศมี 6 หน่วยเป็น Sanctuary และ Waygate อยู่ (6,0)

เป็นระบบ Local ตามขอบเขตเดิม ปิดปุ่มเดินทางและไม่แสดงวงจุดเกิด Local ในฉากออนไลน์ การย้ายพื้นที่สร้างมอนสเตอร์ใหม่และทิ้งของบนพื้น ไม่ใช่โลกถาวร ไม่ต้องแก้ SQL

ตรวจด้วย `npm test` และ `npm run build` โดย `tests/spawns.test.ts` ตรวจพิกัดเดินได้ ไม่ทับ Sanctuary ไม่ซ้อนกัน ข้อมูลแผนที่ตรงกับมอนสเตอร์จริง การเกิดใหม่ และเลเวลทั้งสามอาณาเขต

ผลตรวจรอบนี้: production build และ TypeScript ผ่าน; tests ผ่าน 42/43 รวมการทดสอบแผนที่ใหม่ทั้งหมด รายการที่ไม่ผ่านคือ Warrior GLB ใน `tests/characters.test.ts` เนื่องจาก GLTFLoader โหลด texture บน Node แล้วพบ `self is not defined` ไม่ได้แก้ไฟล์โมเดลหรือชุดทดสอบตัวละครในงานนี้ ยังไม่ได้ยืนยันภาพ/การคลิกในเบราว์เซอร์ เพราะเครื่องมือเบราว์เซอร์เชื่อมต่อ localhost แล้ว timeout
