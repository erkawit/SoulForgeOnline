# SOULFORGE — โมเดลตัวละคร Class I

## ส่งมอบ
ไฟล์ GLB สร้างใหม่ 5 อาชีพ: Warrior, Mage, Priest, Archer, Enchanter พร้อมชุดและอาวุธประจำอาชีพ โครงกระดูก 23 จุดต่อโมเดล มีผ้าลำตัวแบบ skin weights และเกราะ/อาวุธแข็งที่ผูกกับข้อต่อ

ขนาดประมาณ 0.57–0.67 MB ต่อไฟล์, 6,932–10,360 triangles ต่อโมเดล ใช้วัสดุ PBR สีพื้นและส่วนเรืองแสง ไม่ใช้ภาพหรือโมเดลจาก MU / Diablo

ทั้ง 5 ไฟล์มี 9 clips: Idle, Walk, Run, Attack, Skill, Buff, Special, Hit, Death
- คลิปเดิน/วิ่งอยู่กับที่ ระบบเกมเป็นผู้ย้ายตำแหน่ง
- โครงกระดูก Y-up หันหน้า +Z หน่วยเมตร ตำแหน่งเริ่มต้นที่พื้น
- WeaponR และ WeaponL เป็นจุดยึดอาวุธ
- โมเดลอยู่ใน public/models/characters; manifest.json บอกขนาดและรายละเอียด
- ต้นฉบับแก้ไข/สร้างใหม่ได้จาก scripts/build-characters.mjs ด้วย node scripts/build-characters.mjs ภายในโปรเจกต์ที่ติดตั้ง dependencies แล้ว

## ใช้งานในเกม
ตัวละคร Class I โหลด GLB ตามอาชีพโดยอัตโนมัติ เปลี่ยนตามสถานะเดิน โจมตี สกิล บัฟ สกิลพิเศษ และตาย จากระบบเดิม ใช้ cross-fade ระหว่างคลิป เล่นท่าโจมตีซ้ำได้ และค้างท่าตายจนฟื้นชีวิต

เปิด /characters หรือกดลิงก์ห้องดูโมเดลใน Field Journal เพื่อหมุนดู ซูม ทดลอง 9 คลิป และดาวน์โหลดไฟล์แยก

ระบบความเสียหาย ไอเทม เลเวล เซฟ และ Supabase ใช้กฎเดิม ไม่ต้องนำเข้า SQL เพิ่ม รุ่นนี้ไม่ได้เปิดระบบสกิลทั้งหมดที่เคยออกแบบไว้

## ขอบเขต
- เป็นโมเดล Low-poly ต้นแบบสำหรับเว็บ ไม่ใช่งานปั้นสมจริงระดับภาพคอนเซ็ปต์ ไม่มี texture ภาพวาดละเอียด, facial rig หรือ cloth simulation
- Class II/III และผู้เล่นอื่นในโหมดออนไลน์ยังใช้ตัวแสดงผลเดิม ชุดนี้ทำ Class I ทั้ง 5 ก่อนตามลำดับงาน
- Run และ Hit มีในไฟล์และห้องทดลอง; การเล่นจริงยังใช้ Walk และระบบสถานะเดิม ไม่เพิ่มกฎวิ่งเร็วหรือทำให้ติดชะงัก
- Tier อาวุธเปลี่ยนสีอัญมณี; รูปทรง GLB ยังเป็นชุดพื้นฐาน ไม่ได้สร้างอาวุธครบ 8 Tier
- มอนสเตอร์ยังไม่ได้เปลี่ยนเป็น GLB ในชุดนี้
- แอนิเมชันสร้างด้วย keyframes ไม่ใช่ motion capture ยังปรับมือจับอาวุธและการชนผ้าเพิ่มเติมได้

## การตรวจสอบ
ผ่าน production build และ 40 automated tests รวมโหลด GLB ทั้ง 5, ตรวจ skin weights, clone กระดูกแยกอิสระ และเล่น animation ทุกคลิปหลายช่วงเวลาโดยไม่มี matrix ผิดปกติ

ตรวจภาพโมเดลทั้ง 5 ในหน้าเว็บจริง และตรวจท่าเดิน/ตาย แก้ตำแหน่งคทา Priest และขาในท่าตายแล้ว ภาพใน previews เป็นภาพจากตัวแสดงผลจริง ไม่ใช่ภาพ AI

ยังไม่ได้วัดประสิทธิภาพบนโทรศัพท์จริงหรือทดสอบออนไลน์หลายคน แต่ละโมเดลมี mesh ย่อยจำนวนมาก จึงควรรวม draw calls และทำ LOD ก่อนใช้กับฉากที่มีตัวละครจำนวนมาก

## อัปเดต Warrior (โมเดลจาก public/art/3dmodel/1.warrior.glb)
- warrior.glb ใหม่: ลดจาก 2.8 ล้านเหลือ 59,998 triangles, 5.1 MB, texture สี 2048 + normal/metal-rough 1024
- โครงกระดูก 23 จุดชื่อเดิม ฝั่ง R คือแขน/ขาขวาของตัวละคร (ถือดาบ), L ถือโล่; ดาบผูกแข็งกับ HandR โล่ผูกกับ ForearmL
- 9 clips เดิม (Idle, Walk, Run, Attack, Skill, Buff, Special, Hit, Death) ทำใหม่ตาม public/art/warrior-motion.png; Idle = ท่าที่ปั้นมา, ทุกเฟรมเท้าแตะพื้น y=0
- ไม่มีวัสดุ SoulGlow จึงยังไม่เปลี่ยนสีตาม Tier อาวุธ (วงแหวนใต้เท้ายังเปลี่ยนสีตามปกติ)
- ไฟล์เก่าเก็บไว้ที่ blender/backup/warrior_lowpoly_v1.glb และ manifest_v1.json
- สร้างซ้ำได้: blender/ai/decimate_ai.py (Blender) แล้ว python blender/ai/rig_ai_warrior.py <lod.glb> blender/ai/make_warrior_rig.py <out.glb>
- ข้อควรระวัง: public/art/3dmodel/1.warrior.glb (91 MB) อยู่ใน public จะถูกรวมตอน deploy ควรย้ายออกจาก public
