## 1. แม่แบบตัวละคร (ทุกอาชีพ)

### 1.1 ท่าและจำนวนเฟรม — เหมือนกันทุกอาชีพ
| ท่า | ไฟล์ | เฟรม/ทิศ | จังหวะสำคัญ | ใช้ตอน |
|---|---|---|---|---|
| ยืน | `<Class>_idle.png` | 4 | วนลูป | ยืนเฉย |
| เดิน | `<Class>_walk.png` | 6 | วนลูป เท้าซ้าย-ขวาสลับชัด | เดิน/วิ่ง |
| โจมตีธรรมดา | `<Class>_attack.png` | 6 | **เฟรม 4 = จังหวะโดน** | ตีปกติ |
| โจมตีสกิล | `<Class>_skill.png` | 6 | **เฟรม 4 = จังหวะปล่อยสกิล** | สกิลโจมตี |
| บัฟ | `<Class>_buff.png` | 4 | เฟรม 3 = แสงบัฟสูงสุด | บัฟ ฮีล โล่ |
| ตาย | `<Class>_death.png` | 5 | เฟรม 5 = นอนนิ่ง (ค้าง) | ตาย |

- **ส่วนที่เหมือนกันทุกอาชีพ** (ห้ามเปลี่ยน): ยืน 4 / เดิน 6 เฟรม, จำนวนทิศ, ขนาดตัว, มุมกล้อง, ตำแหน่งเท้า
- **ส่วนที่แต่ละอาชีพต่างกันได้**: ลักษณะท่าโจมตีธรรมดา, ท่าสกิล, ท่าบัฟ, ท่าตาย (จำนวนเฟรมยังต้องเท่าตาราง)

### 1.2 รูปแบบชีต (ใช้แบบเดียวกับ monster-sheets ที่ทำไว้แล้ว)
- **8 แถว = 8 ทิศ** เรียงบนลงล่าง:
  - S (หันหน้าเข้ากล้อง)
  - SW
  - W (ข้างซ้าย)
  - NW (เฉียงหลังซ้าย)
  - N (หันหลัง ไม่เห็นหน้า)
  - NE
  - E (ข้างขวา)
  - SE
- คอลัมน์ = เฟรมตามตาราง 1.1 (เช่น walk = 6 คอลัมน์)
- PNG พื้นโปร่งใสจริง ไม่มีพื้น ไม่มีเงา ไม่มีตัวหนังสือ ไม่มีเส้นตาราง
- มุมกล้อง orthographic มองลง ~30° สัดส่วน chibi หัว ~1/3 ของตัว
- ตัวละครอยู่ในกรอบ **60% ของความกว้างช่อง และ 65% ของความสูงช่อง** ช่องว่างระหว่างแถว/คอลัมน์กว้าง อาวุธห้ามล้นเข้าช่องข้าง
- ขนาดตัวและตำแหน่งเท้า **เท่ากันทุกช่อง** (กล้องไม่ขยับ ตัวไม่ขยายตอนโจมตี)
- ชีตเดิมแบบ 5 แถว (S, SW, W, NW, N แล้วเกมกลับด้าน) ยังใช้ได้ แต่ของใหม่ให้ทำ 8 แถว เพื่อให้มือถืออาวุธถูกข้างทุกทิศ

### 1.3 Prompt ตัวละคร (เปลี่ยนเฉพาะส่วน [ ])
```
Create ONE [ACTION] sprite sheet of the EXACT character in the attached idle reference: [CLASS DESCRIPTION].
No redesign, same face, outfit, colours and weapon. Painted dark-fantasy isometric RPG style, chibi proportions
(head about 1/3 of the body). Genuine transparent PNG, EXACTLY 8 ROWS and [N] COLUMNS.
Fixed orthographic camera about 30 degrees down. Row1 SOUTH facing the viewer; row2 SOUTH-WEST three-quarter front left;
row3 WEST pure left profile; row4 NORTH-WEST three-quarter back left; row5 NORTH full back with NO face;
row6 NORTH-EAST three-quarter back right; row7 EAST pure right profile; row8 SOUTH-EAST three-quarter front right.
Every row has the SAME [N]-phase action: [PHASES — e.g. frame1 guard, frame2 wind-up, frame3 swing, frame4 CONTACT,
frame5 follow-through, frame6 recover]. The weapon stays in the same hand in every row.
Fixed character scale and foot anchor in every cell; the camera does not move; the body does not grow during the action.
Leave very wide EMPTY transparent gutters: the character with weapon fits inside the central 60% of the cell width and
65% of the cell height; nothing touches or crosses into a neighbouring cell.
No ground, ground shadow, scenery, effects trails, text, labels, grid or borders.
```

## 3. แม่แบบบอส

- **ท่าครบเท่าตัวละคร 6 ท่า**: ยืน / เดิน / โจมตี / สกิล / บัฟ (ปลุกพลัง คลั่ง) / ตาย — จำนวนเฟรมตามตาราง 1.1
- รูปแบบชีต 8 แถว เหมือนข้อ 1.2 เพียงแต่ในชีตให้วาดเต็มช่องได้ (ไม่ต้องย่อ) เพราะเกมขยายเอง
- **ขนาดในเกม = 5 เท่าของตัวละคร** (ความสูงบนจอ) เกมตั้งค่าที่ตัวคูณขนาด ไม่ต้องวาดใหญ่ในภาพ
- เพราะตัวใหญ่ 5 เท่า: จุดเกิดบอสต้องมี **ลานโล่งรัศมีอย่างน้อย 6 ม.** (ไม่มีต้นไม้ หิน อาคาร) — ดูข้อ 4.3
- ท่าสกิลบอสต้องมี **วงเตือนก่อนโจมตี** (telegraph) ให้ตรงกับเฟรม 2–3 ของท่าสกิล แล้วดาเมจลงที่เฟรม 4

## 4. แม่แบบแผนที่

### 4.1 โครงสร้างร่วมทุกแผนที่
- พื้นที่เดินได้เป็นสี่เหลี่ยม ±ขอบ (เมือง ±CAPITAL_WALK, ฟาร์ม ±23, Ashen Outskirts ±50)
- **ประตู (waygate)** อยู่ที่มุมแผนที่เสมอ: ฟาร์ม/ดันเจี้ยนที่ (±17.5, ±17.5), เมืองที่ (±27, ±27)
- ทุกจุดที่ตัวละคร มอนสเตอร์ หรือบอสจะ "เกิด" ต้องผ่าน `walkable()` = ไม่ทับอาคาร ต้นไม้ หิน น้ำ กำแพง

### 4.2 เมือง
| โซน | ตำแหน่ง | สิ่งที่อยู่ |
|---|---|---|
| ลานกลาง | รัศมี ~6.5 ม. จากกลาง | จุดเกิดผู้เล่น 8 จุด (CAPITAL_SPAWNS), แท่นวิญญาณ |
| ถนนหลัก | แกน + สองเส้นตัดกลาง | ห้ามวางของขวาง |
| ย่าน NPC | รอบลานกลาง | ร้านค้า โรงตีเหล็ก ภารกิจ (NPC ยืนหน้าอาคาร) |
| ประตู 4 มุม | (±27, ±27) | ไปฟาร์ม/เมืองอื่น |
- **ไม่มีมอนสเตอร์ในเมือง** · ของตกแต่งใช้ kit ของเมือง (tree, lamp, crate, wall, corner)

### 4.3 แผนที่ฟาร์มมอนสเตอร์ (ใช้แล้วในโค้ด: `CAMP` ใน `content.ts`, `spawns.ts`)
```
          ประตูกลับเมือง (มุม)
     ┌──────────────────────────────┐
     │  วงตกแต่งขอบ (ต้นไม้/หิน)       │  r ≥ 16 ม.  — ห้ามมีมอนสเตอร์
     │    ●●●  ค่าย A2     ค่าย B1 ●●● │
     │  ●●● ค่าย A1   [ลานกลาง]   ค่าย B2 ●●●│  ค่ายวงแหวน r ≈ 13 ม.
     │    ●●●  ค่าย C2     ค่าย C1 ●●● │
     │                              │
     └──────────────────────────────┘
          ประตูดันเจี้ยน (มุมตรงข้าม)
```
- **6 ค่าย** วางรอบวงแหวนรัศมี ~13 ม. (ค่ายละ 60°)
- **มอนสเตอร์ชนิดเดียวกันอยู่ 2 ค่ายติดกัน**:
  - ชนิดแรก = ค่าย 1–2
  - ชนิดที่สอง = ค่าย 3–4
  - ชนิดที่สาม = ค่าย 5–6
  - ชนิดไม่ปนกัน
- **ค่ายละ 3 ตัว** อยู่รอบจุดกลางค่ายรัศมี 1.8 ม. (กระจุกตัว)
- ระยะห่างกลางค่ายถึงค่ายอื่นอย่างน้อย 9 ม.
- ห่างประตูอย่างน้อย 8 ม. (เข้าแผนที่แล้วไม่ตกลงกลางฝูง)
- **ห่างอาคาร/น้ำ ≥ 3.2 ม.** ค่ายไหนติดของ ระบบเลื่อนค่ายไปตามแนววงหรือขยับเข้า/ออกเองจนโล่ง
- ต้นไม้ หิน และพุ่มไม้ถูกกันไม่ให้วางในรัศมีค่าย (3.2 ม.) — ป้องกันมอนสเตอร์ติดในของ
- วงตกแต่งขอบอยู่ที่ r ≥ 16 ม. ซึ่งอยู่นอกพื้นที่ค่ายทั้งหมด
- มอนสเตอร์ไล่ตามได้ไม่เกิน 13 ม. จากบ้านแล้วกลับค่าย และไม่ตามเข้าใกล้ประตู 6 ม.

### 4.4 ดันเจี้ยน
- เส้นทางเดียว: ทางเข้า → ห้องย่อย 3–4 ห้อง (มอน 2 ชนิด แยกห้องกัน) → **ห้องบอสท้ายสุด**
- จุดมอนสเตอร์ = จุดในเส้นทาง (`hunt`), จุดสุดท้ายคือบอสเสมอ (เกิดใหม่ 300 วิ)
- ห้องบอสต้องเป็นลานโล่งรัศมี ≥ 6 ม. (บอสใหญ่ 5 เท่า) ประตูกลับอยู่มุมล่าง

## 5. แม่แบบ UI (ใช้ชุดภาพใน `src/asset/ui` + ไฟล์ json)

**ไฟล์ต้นฉบับ → ชิ้นที่ใช้ในเกม**: `python3 scripts/ui/build_ui_kit.py` ตัดทุกชิ้นตามพิกัดใน json → `public/art/ui-kit/<id>.webp` (ตัดพื้นดำเป็นโปร่งใส) + รายการ `src/game/ui/uiKit.ts`

| ใช้กับ | ชิ้น (id ใน json) |
|---|---|
| หน้าต่างหลักทุกหน้า | `panel_main_window_9slice` (9-slice 88) |
| กล่องย่อย / tooltip / แถบสถานะ | `panel_sub_tooltip_9slice` (36) |
| แถวรายการที่เลือก | `panel_list_row_banner_9slice` |
| ปุ่มหลัก / ปุ่มรอง | `btn_primary_crimson` / `btn_secondary_dark_iron` |
| แท็บ (เลือก / ไม่เลือก) | `tab_header_active_glow` / `tab_header_inactive_dark` |
| ปุ่มปิดหน้าต่าง | `btn_icon_close_x` |
| ช่องไอเทม / สกิล | `slot_item_normal_common` (+ rare / magic / selected / locked) |
| หลอด HP / MP / EXP | `hud_status_bar_empty_frame` + `hud_hp/mp/exp_bar_*_fill` |
| ไอคอนเมนูขวา | `menu_01…37` + ไอคอนจาก 6.png (`icon_*`) |
| ไอคอนยา/คัมภีร์ในร้าน | `item_potion_*`, `item_scroll_*`, `item_food_campfire_ration` |

กติกา:
1. ทุกหน้าต่างใช้กรอบ, แท็บ, ปุ่ม และปุ่มปิดชุดเดียวกันหมด
2. สไตล์ UI อยู่ไฟล์เดียว (`src/styles/uikit.css`)
3. จะเปลี่ยนภาพ ให้แก้ json/ภาพต้นฉบับ แล้วรันสคริปต์ใหม่ ไม่ต้องแก้ CSS ทีละจุด
4. ถ้าภาพต้นฉบับใหม่ต้องมี **พื้นโปร่งใสจริง** หรือพื้นดำสนิท
5. ทุกชิ้นต้องมีช่องว่างรอบ ๆ ตามที่ json กำหนด (2x)

## 6. แม่แบบหน้าต่างสกิล
- **ซ้าย = รายชื่อสกิล**:
  - เรียงสกิลใช้งานก่อน แล้วตามด้วยสกิลติดตัว
  - แต่ละแถวแสดงไอคอน, ชื่อ, ขั้น x/10 และปุ่มที่ตั้งไว้
  - สกิลที่ยังเปิดไม่ได้เป็นสีจางและบอก "Lv.ที่ต้องการ"
- **ขวา = คำอธิบาย**:
  - ชื่อ, MP, คูลดาวน์, คำอธิบาย
  - ค่าขั้นปัจจุบันและค่าขั้นถัดไป
  - เงื่อนไขเลเวล
  - ปุ่ม "เรียน / อัปขั้น"
  - ปุ่มตั้งคีย์ 6 ช่อง (Space Q E R T X)
- มือถือ: รายชื่อด้านบน คำอธิบายด้านล่าง
