# โมเดลเมือง 2.5D — 23 ตุลาคม 2026

## ใช้งาน
- เปิด `http://localhost:3002/cities` เพื่อหมุนดูเมือง เปิด/ปิดป้ายจุดฟาร์ม และดาวน์โหลด GLB
- ในเกม J → THREE CITIES มีลิงก์ไปห้องดูโมเดล และเดินทางเข้าเมืองเพื่อเล่น
- GLB: `public/models/cities/hollow.glb`, `dawnveil.glb`, `thornwatch.glb`
- ไฟล์ Blender และภาพเรนเดอร์: `../reference/city-modeling/blender/`

GLB ทั้งสามใช้จริงใน StarterCity แทนรูปทรงเมืองหลักเดิม กล้องเกมเป็น orthographic ล็อกมุมก้ม 54° หมุนรอบแนวตั้งและซูมได้ เมืองใช้ลักษณะจากภาพคอนเซ็ปต์ 2.5D ที่อนุมัติ แต่ยังเป็นโมเดลต้นแบบสีวัสดุ ไม่มี texture/รายละเอียดเท่าภาพวาด ตัวละครและพื้นที่ล่านอกเมือง/ดันเจี้ยนยังใช้โมเดลเดิม

## โครงสร้างไฟล์
โมเดลกำหนด 1 หน่วย = 1 เมตร Y-up, ทิศเหนือ -Z, พื้นที่เดินได้ [-23,23] ทั้งสองแกน Blender นำเข้าเป็น Z-up ตาม glTF importer

กลุ่ม Terrain_and_paths, Sanctuary, Waygate, อาคารแยกชนิด/ลำดับ, Outskirts_scenery และ Monster_farming_clearings แยกแก้ไขได้ วัตถุ Spawn_1…Spawn_6 เป็น empty พร้อม extras ชื่อมอนสเตอร์ เลเวล และพิกัดเดียวกับเกม การรวม mesh ตาม material ภายในแต่ละกลุ่มลดจำนวน draw calls ไม่ได้รวมทุกเมืองเป็นชิ้นเดียว

Hollow Reach มีหลังคาจั่ว หอประตู ช่องหน้าต่าง โรงหลอม และกำแพงเหนือที่บล็อกการเดินจริง Dawnveil มีวิหาร หน้าต่างวงกลม ยอดแหลม คลองและสะพาน Thornwatch มีโครงไม้ ค้ำยัน หอเฝ้าระวังและแนวต้นไม้ รอบนอกมีวงจุดฟาร์มและวัตถุประกอบ

พื้นเดินได้อยู่ระดับ y=0 เพื่อให้ตรงกับระบบเคลื่อนที่เดิม ระดับสูงใช้กับฐานอาคาร/สิ่งปลูกสร้าง ไม่ได้เพิ่มระบบเดินขึ้นบันไดหรือ navmesh ภูมิประเทศสามมิติเต็มรูปแบบ

## สร้างใหม่
`npm run models:cities` สร้าง GLB และ manifest จาก `scripts/build-cities.mts` โดยใช้ข้อมูลใน `src/game/content.ts` และ `src/game/spawns.ts`

ใช้ Blender background รัน `scripts/render-cities.py` เพื่อ import GLB, save .blend, และเรนเดอร์ภาพจริง สามารถรันซ้ำหลังแก้ geometry ได้

## ตรวจสอบ
GLB นำเข้าผ่าน GLTFLoader และ Blender สำเร็จครบ 3 เมือง, geometry ไม่มีค่า NaN, anchor ตรงกับมอนสเตอร์, mesh ต่อเมือง 65–69 ชิ้น, ประมาณ 19,000–24,000 triangles การทดสอบเมืองใหม่ 7 รายการผ่าน รวมเดินจาก Sanctuary ไปทุกจุดฟาร์มและ collision ประตู/สะพาน

ชุดทดสอบทั้งหมดผ่าน 49/50 รายการ ที่ไม่ผ่านเป็น Warrior texture loader ใน Node (`self is not defined`) ซึ่งพบก่อนงานนี้ เบราว์เซอร์ในแอปรายงานไม่มี WebGL จึงมีภาพเรนเดอร์ Blender สำรองใน /cities โดยติดป้ายชัดเจน ไม่ใช่ภาพจาก live WebGL
