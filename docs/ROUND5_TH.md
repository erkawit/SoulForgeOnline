# SoulForge Online — รอบ 5: 3 เมืองหลวง + พื้นที่นอกเมือง + NPC ประจำอาคาร

## ผลการเช็คแผนที่
- ทั้ง 3 เมืองเดิมมีพื้นที่เดินได้แค่ ±23 ม. (โมเดล GLB ปูพื้นถึง ±24 และมีพื้นต่ำรอบนอกถึง ±32) — Hollow Reach ขยายไป ±50 แล้วตั้งแต่รอบ 2 (Sorrowlands)
- **ขยายได้ทั้งหมด** โดยไม่ต้องแก้ GLB: เพิ่มพื้นนอกเมืองของเราเองใต้โมเดล แล้วตั้ง `WORLD_LIMIT` = 50 ทั้ง 3 เมือง
- คลองของ Dawnveil (x 6–10) ต่อยาวถึงขอบแผนที่ทั้งเหนือและใต้ ข้ามได้ที่สะพาน 3 แห่ง (z = 0, −30, +28 — `water.bridges`)

## อาคารจากชีต free-texture (`blender/sprites/cut_city_sheet.py` + `city_<เมือง>.json`)
- **Dawnveil 33 ชิ้น**: มหาวิหาร โถงโดม โบสถ์ โบสถ์หอระฆัง บ้าน 7 แบบ กังหันลม ท่อส่งน้ำ ซากโบสถ์/ซุ้ม/หอ/กำแพง บ้านพัง โรงสีพัง สะพาน ท่าเรือ เรือ รูปปั้น 3 ตัว คริสตัล ต้นซากุระ ต้นสน ลานพื้นกลางเมือง
- **Thornwatch 43 ชิ้น**: ลานเข็มทิศ โรงตีเหล็ก (มีปล่องไฟ) โถงผู้พิทักษ์ บ้าน 8 แบบ กระท่อม 2 แบบ ซุ้มราก/กำแพงราก 4 ชิ้น โรงสีน้ำ ยุ้งฉาง โรงเก็บของ ไร่ 2 แบบ กองฟาง ลัง ถัง หีบ เกวียน ธง คบไฟ โคม รั้ว เสาโอเบลิสก์ คริสตัล ต้นไม้
- ตัวเลขกำกับใต้ชิ้นในชีตถูกลบออกอัตโนมัติ · ส่งออกที่ 2× · ใช้ข้ามเมืองได้ (`'thornwatch/crops'`)
- อาคารมี collider ตามขนาดฐาน (`foot`) · ซุ้มประตูกันเฉพาะเสา (`legs`) · สะพาน/ท่าเรือวาดโดยไม่บังตัวละคร (`under`)

- **เขตปลอดภัย + ล่าเบา ๆ ที่ขอบ**: จุดเกิดมอนสเตอร์ของ Dawnveil / Thornwatch ย้ายไปที่ขอบแผนที่ (ห่างลาน 35–46 ม.) เลเวล 1–10 พื้นตรงนั้นสีเข้มกว่าให้รู้ว่าเป็นที่ล่า
- ต้นไม้ หิน พุ่มไม้ วางเพิ่มนอกเมืองอัตโนมัติ (ไม่ทับถนน อาคาร คลอง จุดล่า) และป่ารอบขอบแผนที่
- โมเดล GLB: ซ่อนอาคารบล็อก ลานกลาง จุดล่าในเมืองเดิม และฉากรอบนอกเดิม (`hideGlb`)

**ทำไมเลือกแบบนี้**
- บริการที่ทุกคนต้องใช้บ่อย (ซื้อ ขาย ตลาด ตีบวก เดินทาง) มีครบทุกเมือง ไม่ต้องวาร์ปไปมา
- Hollow Reach เป็นเมืองเริ่มต้น → ผู้นำทาง ชุดเริ่มต้น และพรมือใหม่อยู่ที่นี่
- Dawnveil เมืองวิหาร → ครูสอนสกิลอยู่ที่บันไดมหาวิหาร
- Thornwatch เมืองพรานป่า → พรานเคสเทรล บอกจุดล่ารอบเมือง (ทิศ ระยะ เลเวล) และขายเสบียงพราน (อาหารบัฟ)

**ผลกระทบ**
- เควส "วิชาของอาจารย์อีโซลด์" (Lv3) และ "ล่าอย่างผู้ชำนาญ" (Lv4) ย้ายผู้ให้เควสเป็นผู้เฒ่าคอร์วิน เพราะผู้เล่นใหม่ยังอยู่ใน Hollow
- รีเซ็ตสกิลทำได้เฉพาะที่ Dawnveil
- ภาพของพรานเคสเทรลเป็นภาพชั่วคราว ทำจากชีตนักธนูหญิง (กลับด้าน ผมสีเถ้า) ควรวาดภาพจริงภายหลัง

## พรีวิว
- เดินทางระหว่าง 3 เมืองได้ที่ผู้เฝ้าประตูออร์ริน หรือกด F ที่ศิลาวาร์ป · ปาร์ตี้ไปด้วย · โหลดโมเดลเมืองเมื่อไปถึงครั้งแรก (~2 MB)
- แผนที่โลก (M) แสดงทั้งพื้นที่ ±50: อาคาร คลอง สะพาน จุดล่า และ NPC
