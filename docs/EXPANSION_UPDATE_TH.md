# SOULFORGE — Armory, SoulGod Exchange & Elite Dungeons

รุ่นอัปเดต 22 ตุลาคม 2026 ต่อจาก Class 3 release

## สิ่งที่ใช้งานได้ในรุ่นนี้

- แค็ตตาล็อก 174 รายการ: เกราะ 96 ชิ้น (3 ประเภท × 4 ช่อง × 8 ระดับ), เครื่องประดับ 32 ชิ้น, อาวุธพื้นฐาน 40 ชุด, วัตถุดิบ/ของขาย 6 รายการ
- Common ขาว → Uncommon เขียว → Rare ฟ้า → Epic ม่วง → Legendary แดง → God ทอง → Pre-arch ส้ม → Arch ม่วงอมทอง
- Warrior ใช้เกราะหนัก, Archer ใช้เกราะเบา, Mage/Priest/Enchanter ใช้ชุดคลุม ชิ้นเกราะประกอบด้วยอก หมวก ถุงมือ รองเท้า
- ช่องอุปกรณ์ 6 ช่อง: อาวุธ อก หมวก ถุงมือ รองเท้า เครื่องประดับ เครื่องประดับเลือกได้ 1 ชิ้นจาก 4 แนวทาง
- ภาพอุปกรณ์ใหม่ 5 แผ่น แยกจากภาพตัวละคร ใช้แสดงภาพรายชิ้นใน tooltip ด้วยตำแหน่งบน atlas พร้อมชื่อ ระดับ ค่าสถานะ คำอธิบาย และราคาขาย NPC
- ชี้เมาส์/โฟกัสเพื่อดูรายละเอียด แตะเพื่อค้างหน้ารายละเอียด หรือกดค้าง 450 ms การลากเกิน 10 px ยกเลิกการกดค้าง
- ขายไอเทมในกระเป๋าให้ NPC ได้ มีหน้าต่างถามยืนยันทุกครั้ง ราคาทั่วไป 1–24 SoulGod ของที่สวมอยู่ต้องถอดก่อน ของที่ลงตลาดต้องถอนก่อนขาย
- อาวุธ/เกราะที่ดรอปใช้แค็ตตาล็อกใหม่ ค่าสถานะมีผลกับการต่อสู้ต้นแบบ ข้อจำกัดเกราะ/อาวุธอิงอาชีพหลัก
- เซฟเก่ายังคง version 1 เพิ่ม economyVersion:2 เพื่อแยกการเปลี่ยนชื่อ rarity เก่า Crimson → Legendary, Legendary เก่า → God, Ascendant → Pre-arch, Eclipse → Arch คงค่าพลังเดิม

## ตลาดกลางและ SoulGod

เปิด J → ITEMS / SKILLS / MARKET → ตลาดกลาง

SoulGod (SG) เป็นเงินจำนวนเต็ม ตราสัญลักษณ์เหรียญทอง ดวงวิญญาณสีม่วงและสุริยุปราคา ภาพต้นฉบับอยู่ที่ public/art/soulgod.png

ตลาดออนไลน์เชื่อม Supabase โดยตรงผ่าน RPC ลงขายทั้งกอง ซื้อทั้งกอง และถอนรายการได้ ไม่มีค่าธรรมเนียมในต้นแบบ ราคา 1–1,000,000,000,000 SG รายการล่าสุดสูงสุด 200 รายการพร้อมค้นหาภายในชุดที่โหลด

เงินใช้ player_wallets.gold ของฐานข้อมูลเดิม เปลี่ยนชื่อที่แสดงเป็น SoulGod ไม่ย้ายยอดเงินไปตารางใหม่ ไอเทมใช้ inventory_items เดิม ทุกชนิดในตารางนี้ลงตลาดได้ รวมทั้งวัตถุดิบและไอเทมเดิมที่ไม่มีในแค็ตตาล็อก (NPC ให้ 1 SG ต่อหน่วยถ้าไม่มีราคากำหนด)

การซื้อใช้ราคาในฐานข้อมูล ตรวจเจ้าของ/ยอดเงิน ล็อกบัญชีและรายการ โอนเงินและไอเทมในธุรกรรมเดียว ป้องกันซื้อซ้ำ ลงขายซ้ำ และขาย NPC ขณะไอเทมอยู่ในตลาด ผู้เล่นเขียนยอดเงินหรือไอเทมโดยตรงไม่ได้

**แยกจาก Guest Save:** เงิน ไอเทม และรางวัลดันเจี้ยนในโลกทดลองไม่ส่งเข้ากระเป๋าออนไลน์ เซฟตัวละครเป็นข้อมูลที่ผู้เล่นแก้ไขได้ จึงใช้สร้างเงินหรือไอเทมตลาดจริงไม่ได้ ระบบ farm_cards เดิมยังเป็นสิทธิ์ใช้งานอีกตารางหนึ่ง ยังไม่แปลงเป็น inventory_items สำหรับซื้อขาย

## ติดตั้งฐานข้อมูล

หากมี Phase 1 + Phase 2 แล้ว: รัน soulforge-supabase-market-update.sql ใน SQL Editor ของโปรเจกต์นั้นหนึ่งครั้ง (รวม migration 003 และ 004)

หากเป็น Supabase ใหม่: รัน soulforge-supabase-expansion-new-project.sql ซึ่งรวม migration 001–004 ห้ามใช้ไฟล์ติดตั้งใหม่กับโปรเจกต์ที่เคยติดตั้งแล้ว เพราะ policy เดิมไม่ได้ออกแบบให้รันซ้ำ

ตั้งค่า NEXT_PUBLIC_SUPABASE_URL และ NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY ใน Vercel แล้ว redeploy เข้าสู่ระบบผ่าน Cloud Save เปิดตลาดและกดโหลดตลาด ไอเทม/เงินออนไลน์ต้องมาจากระบบเซิร์ฟเวอร์ที่เชื่อถือได้ เช่นระบบเดิมที่ใช้ inventory_items และ player_wallets

ไม่มีการแก้ไข Supabase จริงหรือ deploy Vercel จากงานรอบนี้ ไม่ต้องรัน SQL เพื่อดูภาพหรือเล่นโลกทดลอง แต่ต้องรันก่อนใช้ตลาดออนไลน์

## สมุดสกิลและภาพไอคอน

มีข้อมูล 320 สกิล/ช่องไอคอน รวม 5 อาชีพและสายแยก ภาพต้นฉบับ 5 แผ่น 8×8 ช่องต่ออาชีพ

| คลาส | ต่อหนึ่งอาชีพ/สาย | สถานะ |
|---|---|---|
| 1 | Active 4 + Passive 4 | 5 อาชีพพื้นฐาน |
| 2 เลเวล 10 | Active 6 + Passive 6 + Ultimate I | 10 สาย |
| 3 เลเวล 60 | Active 3 + Passive 4 + Ultimate II | 10 สาย |
| 4 | Active 3 + Passive 3 + Architected | 10 สาย ข้อมูลสำรอง ยังล็อก |

นับเป็นสกิลใหม่ของแต่ละคลาส สืบทอดสกิลคลาสก่อนหน้าของสายที่เลือก ดังนั้นหนึ่งสายถึง Class 3 มี 29 รายการในสมุดสกิล

Ultimate I กับ II เลือกได้เพียงหนึ่งแบบ Architected ใช้ร่วม II ได้ แต่ห้ามร่วม I หน้าสมุดมีตัวอย่างการเลือกและฟังก์ชันตรวจสอบกติกา ยังไม่บันทึกเป็นชุดสกิลต่อสู้จริง

**ขอบเขต:** ไอคอน ชื่อ คำอธิบาย จำนวน และโครงสร้างสายอาชีพพร้อมแล้ว แต่สกิลทั้งหมดไม่ได้เปิดใช้จริง การต่อสู้ยังใช้ Space/Q/E ต้นแบบเดิม พร้อมภาพไอคอนใหม่ ค่าตัวเลขบางส่วนเป็นแนวทางออกแบบ การชุบชีวิต/เรียกเพื่อน/บัฟปาร์ตี้ต้องต่อระบบปาร์ตี้ฝั่งเซิร์ฟเวอร์ โบนัสธาตุเฉพาะยังไม่แยกจากความเสียหายต้นแบบ

เข้าทางวงวาร์ปที่พิกัด (6,0) ของแผนที่ทางเข้า เดินเข้าใกล้ไม่เกิน 4 หน่วยแล้วกดป้าย มีทางกลับภายนอก และเข้าโดยตรงจากสมุดเดินทางได้เพื่อทดลอง

มอนสเตอร์ดันเจี้ยนเป็น Elite ทั้งหมด HP และโจมตีพื้นฐาน ×3, EXP ×5 เมื่อเทียบเลเวลเดียวกัน บอส HP อีก ×5 จาก Elite เพื่อเป็นศึกประจำดันเจี้ยน บอสเกิดใหม่ 5 นาที มอนสเตอร์ทั่วไป 8 วินาที การเข้าโซนใหม่ในโลกทดลองสร้างสถานะมอนสเตอร์ใหม่ ไม่ใช่โลกถาวร

บอสดรอปอาวุธ Warrior/เกราะหนัก/เครื่องประดับป้องกันเป็นชุดต้นแบบแน่นอน ส่วนการดรอปมอนสเตอร์ทั่วไปสุ่มจากอุปกรณ์ทุกสาย ยังไม่มีระบบคราฟจริงหรือการปรับสมดุลเศรษฐกิจระยะยาว

กติกาที่เตรียมไว้: เขตเมืองและ Sanctuary ปลอดภัย รอบเมืองแรกและดันเจี้ยนแรกต้อง Class 2 ทั้งผู้โจมตีและเป้าหมายจึง PK ได้ ส่วนพื้นที่เมือง 2–3 เป็น FreePK ระบบข้อมูลรองรับกติกานี้ แต่ **ปาร์ตี้และ FreePK ยังไม่เชื่อมเซิร์ฟเวอร์จริง** เซิร์ฟเวอร์ออนไลน์เดิมยังเป็นห้อง World Boss เดิม ไม่ใช่แผนที่ใหม่ทั้งหมด

## งานภาพและข้อจำกัด

ภาพใหม่เป็น raster concept/icon atlas ไม่ใช่ไฟล์โมเดล rigged FBX/GLB ภาพเกราะไม่ได้เปลี่ยนตัวละคร 3D ให้มีรายละเอียดเท่าภาพโดยอัตโนมัติ โมเดลในโลกยังเป็นชิ้นส่วน 3D ต้นแบบเดิม งานทั้งหมดเป็นรูปทรงและชื่อที่ออกแบบใหม่ ไม่ใช้ asset จาก MU หรือ Diablo

## การตรวจสอบ

- Unit tests 30 รายการผ่าน: เซฟ/คลาส/การต่อสู้เดิม, อุปกรณ์/rarity, NPC ไม่ขายหากไม่ยืนยัน, สกิลทุกสาย, กติกา Ultimate, แถบเลเวล, ตัวคูณ Elite, รางวัลบอสไม่ซ้ำ
- Production build และ TypeScript ผ่าน
- รัน migration 001–004 บน PostgreSQL WASM (PGlite) พร้อม auth stub ในฐานข้อมูลทดสอบ ผ่าน RLS, สิทธิ์เจ้าของ, ซื้อ/ขาย/ถอน, ยอดเงิน, ยืนยัน NPC, ราคาที่เปลี่ยน, ซื้อซ้ำ, ไอเทมเก่า
- PGlite ไม่แทนการทดสอบ concurrent requests หลาย connection หรือระบบ Auth/Supabase ที่ deploy จริง
- ตรวจหน้าแค็ตตาล็อก ภาพ tooltip สมุดสกิล และการสลับ Ultimate ในเบราว์เซอร์แล้ว ไม่มีข้อมูลบัญชีจริงใช้ในการทดสอบ
- สภาพแวดล้อมเบราว์เซอร์แจ้ง WebGL unavailable จึงไม่ถือว่ารับรองภาพ 3D/ประสิทธิภาพ GPU และยังไม่ทดสอบบนโทรศัพท์จริง
