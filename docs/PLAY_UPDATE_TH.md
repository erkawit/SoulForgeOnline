# อัปเดต "พร้อมเล่น" — สิ่งที่เปลี่ยนในรอบนี้

## ขั้นตอนเข้าเกม
1. **ลงทะเบียน** กรอกโค้ดเชิญ XXXX-XXXX-XXXX-XXXX + อีเมล + รหัสผ่าน → ได้บัญชีทันที (`claim_invite_account`)
2. **สร้างตัวละคร** หน้า 3D แสดงทั้ง 5 อาชีพบนแท่นรูน คลิกตัวละครหรือรายชื่อ ดูสเตตัส 6 ค่าและชุดสกิล ตั้งชื่อ → `create_character`
3. เข้าเมือง เซิร์ฟเวอร์ออนไลน์จะไม่ให้เข้าโลกจนกว่าจะสร้างตัวละครแล้ว

## การต่อสู้
| อาชีพ | โจมตีพื้นฐาน (ปุ่ม 1 / คลิกมอนสเตอร์) | ท่าที่ 2 |
|---|---|---|
| Warrior | ฟัน 3 จังหวะ ซ้าย→ขวา→ฟันผ่า (×1 / ×1.1 / ×1.6) | ยกโล่ (Guard) เมื่อใช้ Bastion |
| Archer | แตะ = ยิงเร็ว | **กดค้าง** = ง้างสาย เกจ 1.6 วิ แรง ×1→×3 เต็มเกจคริแน่นอน |
| Mage | ลูกเวท 3 จังหวะ | ร่ายสกิลพร้อมหลอดร่าย (0.4–2.2 วิ ต่างกันทุกสกิล) |
| Priest | ค้อนรุ่งอรุณ | ภาวนา (ท่าพนมมือ) ร่ายฮีล ตนเอง / เพื่อน / ทั้งปาร์ตี้ |
| Enchanter | กระสุนรูน | วาดแขนเป็นวงร่ายบัฟ ตนเอง / เพื่อน / กลุ่ม |

- กดสกิลได้ทุก 0.25 วิ ส่วนคูลดาวน์จริงตัดสินในสโตร์ของเกม · เดินระหว่างร่ายหรือง้าง = ยกเลิก
- ตัวเลขดาเมจขึ้นตอนเอฟเฟกต์กระทบจริง (`HIT_MS`) ไม่ขึ้นก่อนภาพ
- ออร่าสกิลใช้แสงขอบ (fresnel) ตรงกลางโปร่ง จึงไม่กลบตัวละคร

## โลก
- ต้นไม้/หิน/ป้ายหลุมศพ/NPC/ศิลากลางลาน ชนได้จริงผ่าน `walkable()` (registry ลงทะเบียนอัตโนมัติ)
- ลมพัดต้นไม้และหญ้า (ตั้งแรง/ทิศลมได้) หญ้าและพุ่มไม้แหวกออกเมื่อผู้เล่นหรือมอนสเตอร์เดินผ่าน (สูงสุด 16 ตัวใกล้สุด)
- ต้นไม้ที่บังกล้องจะค่อย ๆ โปร่งแบบ dither ให้เห็นตัวละครเสมอ
- มอนสเตอร์เล็กลง 20%

## ปาร์ตี้ (กันหลุด)
- เซิร์ฟเวอร์เก็บรายชื่อ + บันทึกลง `parties / party_members` (RPC `save_party`)
- หลุด/รีเฟรช: ไคลเอนต์ต่อใหม่อัตโนมัติ 1,2,4,8,15… วิ ภายในเวลาจอง 120 วิ กลับเข้าช่องเดิม
- หัวหน้าหลุด → โอนหัวหน้าเมื่อพ้นเวลาจองเท่านั้น · เซิร์ฟเวอร์รีสตาร์ท → กู้ปาร์ตี้จากฐานข้อมูล
- กรอบปาร์ตี้ซ้ายจอแสดงรูปอาชีพ HP/MP และสถานะ "กำลังเชื่อมต่อใหม่ · จองที่ไว้ N วิ"

## ปุ่มใหม่
`1` โจมตี/ง้าง · `P` ปาร์ตี้ · `M` แผนที่โลก · `O` ตั้งค่า · `G` เว็บข้อมูลเกม (/guide)

- `tsx --test`: balance 13 · characters 14 (GLB v2 12 ท่า) · closed-beta 1 · party 4 · play 4 — ผ่านทั้งหมด
- type-check ส่วนที่แก้ผ่าน (ยกเว้นคำเตือนที่มาจาก stub ของ three ในเครื่องทดสอบ)
- ยังไม่ได้รัน `next build` และ game server จริงบนเครื่องคุณ — ให้รัน `npm run build` และ `npm test` หลังรับไฟล์
