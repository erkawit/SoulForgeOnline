# Round 19 — คู่มือออกแบบชุด/อาวุธ/ปีก/ผ้าคลุม และการขยายไปทุกอาชีพ (ใช้ตัว 3D T-Pose ตัวเดียว)

## 1. ตัวละครฐาน (ห้ามเปลี่ยน)

| รายการ | ค่า |
|---|---|
| โมเดล | `hero-base-m.glb` / `hero-base-f.glb` (Meshy → Mixamo) |
| ท่าตอน rig | **T-Pose** แขนตรงระดับไหล่ ฝ่ามือคว่ำ ขาแยกเล็กน้อย |
| โครงกระดูก | Mixamo 65 ชิ้น (มีนิ้วครบ) ชื่อ `mixamorig:*` |
| ความสูงในเกม | 1.75 หน่วย (สัดส่วน chibi หัวใหญ่ ~1 : 3) |
| ทรงผม | ไฟล์แยก 4 ทรง เกมปรับให้พอดีหัวเองทุกตัว |

ทุกอย่างที่ "สวมใส่" ต้องอิงตัวนี้ ทั้งชาย/หญิง แยกไฟล์ตามเพศ เพราะรูปร่างต่างกัน

## 2. ของสวมใส่ 5 แบบ — แต่ละแบบติดกับตัวคนละวิธี

| แบบ | ติดอย่างไร | ต้อง rig ไหม | ตัวอย่าง |
|---|---|---|---|
| **A. ชุดคลุมตัว** (เสื้อ กางเกง เกราะ ชุดอาชีพ ชุดแฟชั่น) | หนังตามกระดูก (skinned) ใช้ weight จากตัวฐาน | ไม่ต้องใช้ Mixamo — ผมโอน weight จากตัวฐานใน Blender | ชุดไทย ชุด Paladin ชุดแฟร์ |
| **B. ของบนหัว** (หมวก มงกุฎ หมวกเกราะ หน้ากาก) | ติดแข็งกับกระดูก Head | ไม่ต้อง | มงกุฎชฎา |
| **C. อาวุธ / อาวุธแฟชั่น** | ติดแข็งกับมือ (socket) | ไม่ต้อง | ดาบใหญ่ มีดคู่ คทา โล่ |
| **D. ปีก / ออร่าหลัง** | ติดแข็งกับกลางหลัง (Spine2) + กระพือด้วยโค้ด | ไม่ต้อง | ปีกแฟร์ |
| **E. ผ้าคลุม** | ติดที่ไหล่ + กระดูกเพิ่ม 3 ท่อนตามความยาว แกว่งด้วยโค้ด (spring) | ผมเพิ่มกระดูกให้ใน Blender | ผ้าคลุมแฟร์ |

### A. ชุดคลุมตัว — กฎออกแบบ (สำคัญที่สุด)
1. **สร้างจากภาพตัวฐานในท่า T-Pose เดียวกันเป๊ะ** สวมชุดทับ — ภาพ 4 ด้าน หน้า/ซ้าย/หลัง/ขวา พื้นหลังโปร่ง ขนาดตัวเท่าเดิม
2. **แขนเสื้อแนบแขน** ยาวได้ถึงข้อมือ แต่ไม่บาน ไม่ห้อย — แขนเสื้อบานคือสาเหตุแขนบิดของชุดไทยรอบแรก
3. **รักแร้และหว่างขาต้องเปิด** ห้ามมีผ้าเชื่อมแขนกับลำตัว หรือขาซ้ายกับขาขวา
4. **กระโปรง/ผ้านุ่งยาว** — ให้สั้นเหนือเข่า หรือแยกเป็นแผ่นหน้า-หลัง (ผมใส่กระดูกผ้าให้แกว่ง) ห้ามเป็นกระบอกเดียวหุ้มสองขา
5. **ความหนา** ชุดห่างผิว 0.5–2 ซม. พอ เกราะหนาได้ถึง 4 ซม. — ยิ่งหนายิ่งเสี่ยงทะลุตอนงอ
6. **ข้อต่อ** (ศอก เข่า ไหล่ สะโพก) อย่าวางชิ้นแข็งขนาดใหญ่คร่อมข้อ — แยกเป็นชิ้นบน/ล่าง
7. **หัว มือ เท้า** ใช้ของตัวฐาน ยกเว้นตั้งใจเปลี่ยน (ถุงมือ รองเท้า) — ถุงมือต้องบาง เพราะนิ้วต้องกำด้ามอาวุธ
8. **โพลิกอน** ชุดทั้งตัว ≤ 15,000 หน้า, เท็กซ์เจอร์ 1024² (เกมย่อเอง)
9. **ส่งไฟล์** GLB/FBX จาก Meshy (ไม่ต้อง rig) ตั้งชื่อ `outfit-<อาชีพหรือชื่อชุด>-<m|f>` เช่น `outfit-paladin-f.glb`

สิ่งที่ผมทำต่อ: วางชุดลงบนตัวฐาน → โอน weight → ลบผิวที่ถูกชุดบัง (กันทะลุ) → ทดสอบทุกท่าในหน้า `/dev-hero` → ใส่เกม

### B. ของบนหัว
- ออกแบบบนหัวตัวฐาน ส่งเป็นชิ้นเดียว ระบุว่า **ซ่อนผม** ไหม (หมวกเต็มหัว = ซ่อน, มงกุฎ = ไม่ซ่อน)

### C. อาวุธ (และอาวุธแฟชั่น) — สเปกไฟล์
- จุดกำเนิด (origin) = ตรงด้ามที่มือจับ, ใบ/ปลายอาวุธชี้ไปทาง **−Z (glTF) / +Y (Blender)**
- **ด้านคม** อยู่บนแกน X (ด้านแบนหันแกน Y) — เกมหมุนให้คมหันหน้าตัวละครเอง
- **ด้ามต้องยาวพอสำหรับจำนวนมือ** — อาวุธสองมือ ด้ามยาว ≥ 22% ของความยาวทั้งเล่ม
- อาวุธแฟชั่นต้องเป็น **ประเภทเดียวกับอาวุธจริง** (ดาบใหญ่แฟชั่นใช้ท่าดาบใหญ่) ด้ามสั้น/ยาวใกล้เคียงของเดิม

| อาชีพ | อาวุธ | จุดติด |
|---|---|---|
| Berserker | ดาบใหญ่สองมือ | มือขวา, ด้ามผ่านสองกำปั้น (ทำแล้ว) |
| Assassin | มีดคู่ | มือขวา + มือซ้าย (ถือกลับด้ามได้) |
| Sorceress | คทาสองมือ | มือขวา, ด้ามผ่านสองกำปั้น (แบบเดียวกับดาบใหญ่) |
| Paladin | ดาบมือเดียว + โล่ | ดาบ: มือขวา / โล่: แขนท่อนล่างซ้าย (LeftForeArm) |

### D. ปีก
- ออกแบบกางปีกด้านหลัง จุดกำเนิดที่กลางสะบัก ไม่ต้อง rig — เกมกระพือ/ลอยเอง
- ปีกใหญ่ไม่เกินความสูงตัว ไม่งั้นบังกล้อง

### E. ผ้าคลุม
- ปั้นผ้าห้อยตรงลงจากไหล่ในท่า T-Pose ยาวถึงน่อง เว้นระยะจากหลัง 2–3 ซม.
- ผมเพิ่มกระดูก 3 ท่อน (บน-กลาง-ล่าง) เกมคำนวณการแกว่งตามการวิ่ง
- ผ้าคลุมกับอาวุธบนหลังห้ามมีพร้อมกัน (หรือยอมให้ทับ)

## 3. ใช้ตัว 3D นี้กับทุกอาชีพได้ไหม — ได้

ตัวฐานใช้ร่วมทุกอาชีพ สิ่งที่ต่างกันมีแค่ 3 อย่าง:

1. **ชุดท่าต่อสู้** (ไฟล์ท่าแยกต่ออาชีพ จาก Mixamo) — ยืน เดิน วิ่ง โจมตี 3 จังหวะ สกิล บัฟ โดนตี ตาย
2. **อาวุธ + จุดจับ** ตามตารางข้างบน (ผมวัดตำแหน่งกำปั้นจริงต่อท่า/ต่อเพศให้เหมือน Berserker)
3. **ชุดอาชีพ** แบบ A ต่อเพศ

โครงไฟล์ที่จะทำ (โหลดเฉพาะที่ใช้ ประหยัดเน็ต/หน่วยความจำ):
```
models/hero/hero-base-{m,f}.glb        ตัว + โครงกระดูก + ผม
models/anims/anim-<class>.glb           ท่าของอาชีพ (ใช้ได้ทั้งชาย-หญิง)
models/outfits/outfit-<id>-{m,f}.glb    ชุดคลุมตัว
models/weapons/<type>-<tier>.glb        อาวุธ / อาวุธแฟชั่น
models/accessories/<id>.glb             หมวก ปีก ผ้าคลุม
```

### ขั้นตอนต่อหนึ่งอาชีพ
1. คุณหาท่าใน Mixamo (ค้นคำว่า dagger, staff, magic, sword and shield, shield block ฯลฯ) ดาวน์โหลดแบบ **Without Skin**, FBX, 30 fps ใส่โฟลเดอร์เดียวกัน
2. ผมรวมเป็น `anim-<class>.glb` ทำให้อยู่กับที่ ปรับความสูงสะโพก
3. คุณสร้างอาวุธ (Meshy) ตามสเปก C → ผมวัดจุดจับในท่ายืน
4. คุณสร้างชุดอาชีพตามกฎ A (ชาย/หญิง) → ผมโอน weight
5. ทดสอบใน `/dev-hero` ทุกท่า → ใส่เกม

## 4. ลำดับที่แนะนำ
1. ปิดงาน Berserker: ชุด Berserker (ชาย/หญิง) ตามกฎ A → ชุดไทยใหม่
2. ระบบ accessory: หมวก/มงกุฎ, ปีก, ผ้าคลุม (ใช้ภาพปีกที่มีอยู่ได้)
3. อาชีพถัดไปทีละอาชีพ: Paladin → Assassin → Sorceress (ใช้ไฟล์ท่าใหม่ + อาวุธใหม่ + ชุดใหม่ บนตัวฐานเดิม)
4. ชุดแฟร์แยกเพศ — ใช้กฎ A เหมือนชุดอาชีพ, อาวุธแฟร์ใช้สเปก C ของอาวุธประเภทนั้น
