# พื้นที่เดินได้และพื้นที่ห้ามเดิน

ข้อมูลนี้ใช้ในพื้นที่เล่นจริง ไม่ใช่เพียงสีบนแผนที่: การเดินด้วยคีย์บอร์ด, คลิกเดิน, หาเส้นทาง, มอนสเตอร์, ท่าพุ่ง/ผลัก และการตรวจตำแหน่งบน realm ใช้กฎเดียวกัน

- ทุกแผนที่มีขอบเขต 140 × 140 เมตร
- พื้นภูมิประเทศแบ่งช่อง 0.5 เมตร (280 × 280 ช่อง) พื้นที่นอกขอบเขตเดินไม่ได้
- เมือง 3 แห่งใช้พื้นเมืองเดิม หักอาคาร กำแพง คลอง ต้นไม้ และ NPC ด้วย collider เดิม
- พื้นที่ฟาร์ม 10 แห่งและดันเจี้ยน 3 แห่งมีทางเชื่อมและลานล่า แผนที่ปิดจะเดินนอกทาง/ลานไม่ได้
- สุสาน wild0 ยังเป็นพื้นที่เปิดตามผังซากเมืองเดิม และใช้กำแพง/ซากอาคาร/หินปิดทาง
- หนองวิญญาณ wild2 ใช้แนวสะพานและขอบลานที่วางตามภาพ `hollow/field-right.webp` พื้นหนองถูกปิดโดยปริยาย จุดเกิดมอนสเตอร์ทั้ง 10 จุดอยู่บนลานแห้ง
- พื้นและเส้นทางในฉาก 3D แสดงจากข้อมูลเดียวกับ collision จึงไม่วาดถนนปลอมผ่านพื้นที่ปิด

## แก้ข้อมูล

`src/game/world/terrainNavigation.ts` เก็บชื่อทาง, จุดตามแนวทาง, ความกว้าง, ลานวงกลมหรือ polygon และพื้นที่ห้ามเดิน (`forbidden`) ซึ่งมีสิทธิ์ปิดทางสูงสุด

- พิกัดเกมใช้ `[x,z]` หน่วยเมตร
- `paths`: ทางเดิน/สะพาน `points` เรียงตามทาง, `width` คือความกว้างเต็ม
- `plazas`: ลานรูป polygon (`points`) หรือวงกลม (`center`, `radius`)
- `openGround: false`: ที่ไม่ได้ระบุเป็นทางหรือลานเดินไม่ได้
- `forbidden`: ห้ามเดินแม้ซ้อนกับทางหรือลาน
- `fieldImagePoint(u,v)`: แปลงพิกัดจากภาพอ้างอิง 1280 × 853 เป็นพิกัดเกม ใช้สำหรับวางลานและสะพานหนองวิญญาณ
- แผนที่ขยายอื่นสร้างทางเชื่อมจากลานมอนสเตอร์และประตูใน `content.ts` เมื่อเปลี่ยนตำแหน่งจึงเชื่อมตามด้วย
- สิ่งปลูกสร้างและ prop colliders ตรวจเพิ่มภายหลัง จึงไม่สามารถเดินผ่านอาคารเพียงเพราะอาคารตั้งอยู่บนลาน

ภาพภูมิภาคเก่าของแผนที่ขยายอื่นยังเป็นภาพแนวคิด ไม่ได้ตรงกับตำแหน่งทุกจุดในโลกที่ขยายแล้ว World Map จึงเปิดผังทางเดินจริงเป็นค่าเริ่มต้น และแยกปุ่มดูภาพอ้างอิงไว้

## ดูและส่งออก

World Map มีปุ่ม **เขตเดินได้**: เหลือง=ทางเดิน, ฟ้าเขียว=ลาน, เขียว=พื้นเดินได้, แดง=ห้ามเดิน ปักหมุดบนพื้นที่ปิดแล้วปุ่มเดินจะใช้ไม่ได้

เรียกจากโฟลเดอร์ `project`:

```powershell
node --import tsx scripts/render-navigation-atlas.mts
```

ผลลัพธ์ใน `output/navigation/`:

- `index.html`: ดูทั้ง 16 แผนที่
- `<id>-navigation.png`: ภาพผังมุม isometric พร้อมจุดวาร์ปและมอนสเตอร์
- `<id>-walkable-mask.png`: หน้ากาก 280 × 280 สีขาวเดินได้ สีดำห้ามเดิน รวมสิ่งกีดขวางแล้ว
- `<id>-navigation.json`: ขอบเขตทาง/ลาน, collider, อาคาร, ประตู, จุดเกิด และ `walkableRows`

หน้ากากเรียงคอลัมน์ตาม x และแถวตาม z จุดกึ่งกลางช่อง `(column,row)` คือ `[-70+(column+0.5)*0.5, -70+(row+0.5)*0.5]` ควรเว้นพื้นที่ให้ขนาด Asset ด้วย ไม่ใช่ตรวจเพียงจุดกึ่งกลางของอาคาร

เมื่อแก้ผังหรืออาคารให้ส่งออกใหม่ และตรวจเส้นทางประตู/จุดเกิดก่อนใช้งาน:

```powershell
node --import tsx --test tests/terrain-navigation.test.ts tests/field-expansion.test.ts tests/world-links.test.ts tests/cities.test.ts
```
